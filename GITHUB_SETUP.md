## Security Note

⚠️ **Important**: The personal access token is stored in the git remote URL. For better security:
1. Consider using SSH keys instead
2. Or use Git Credential Manager
3. Or set up the token as a credential helper

To switch to SSH:
```bash
git remote set-url origin git@github.com:royestheking-a11y/aurangzebsunny-portfolio.git
```
